## Eight-Week Learning Outline

| Week | Theme | Learner outcome | Practical evidence |
| --- | --- | --- | --- |
| 1 | Starting with digital tools | Learners understand the course workspace, file naming, browser use, and safe online participation. | Organised course folder and a short orientation check. |
| 2 | Building a first web page | Learners can use basic HTML structure, headings, paragraphs, lists, and links. | A one-page personal-interest site using sample content only. |
| 3 | Meaningful content and media | Learners can organise content with sections, images, alternative text, and simple forms. | An accessible information page with labelled content. |
| 4 | Visual design with CSS | Learners can apply readable type, colour, spacing, and borders. | A styled version of the previous page. |
| 5 | Layout for different screens | Learners can use flexible layout and responsive design principles. | A page checked at mobile and desktop widths. |
| 6 | JavaScript foundations | Learners can work with variables, inputs, conditions, and simple page interactions. | A small interactive exercise with visible feedback. |
| 7 | Guided mini-project | Learners plan and build a small, ethical project using the skills practised so far. | Project plan, build progress, and facilitator feedback. |
| 8 | Review and next steps | Learners test, explain, and improve their project, then identify a next learning goal. | Final project review and personal learning reflection. |
