# Curated Evidence Source Library — Initial Record

## Purpose and boundary

This record defines the first **reviewable source profiles** for NSOS Learning Design. It supports editable course planning and visible citations. It does **not** make NSOS, a tenant, an AI tutor, or a generated course an approved curriculum provider, accredited institution, certifying body, or regulator.

| Source profile | Permitted use in NSOS | Explicitly not evidence for |
|---|---|---|
| NERDC Basic Education Curriculum | A Nigeria-first reference when an owner/admin chooses a basic-education context; the agent may suggest editable structures and identify the source profile used. | Automatic subject selection, school-specific scheme approval, examination eligibility, accreditation, or learner certification. |
| NERDC Revised Senior Secondary Education Curriculum | A Nigeria-first reference when an owner/admin chooses a senior-secondary context; the agent may suggest age/level-sensitive internal curriculum drafts. | Automatic adoption by a school, governmental endorsement of a tenant’s material, public claims, or awards. |
| UNESCO AI Competency Framework for Students | An optional global pedagogical reference for AI-literacy learning objectives or tutor-scope review. | Nigerian curriculum authority, local policy compliance, accreditation, or evidence that a learner has acquired a competency. |
| Institution-approved source | A tenant-provided, owner/admin-reviewed URL, title, or document reference used only after the institution confirms it has the right to rely on the material. | Independent validation of copyright, currency, accuracy, accreditation, or learner outcome. |

## Verified source findings

The official Nigerian Educational Research and Development Council (NERDC) Basic Education Curriculum page identifies curriculum paths for Primary School 1–3, Primary School 4–6, Junior Secondary School 1–3, and Accelerated Basic Education.[1] The official NERDC revised senior-secondary page identifies curriculum paths for Senior Secondary School 1, 2, and 3.[2]

UNESCO states that its *AI Competency Framework for Students* is intended to help educators integrate AI learning objectives into official curricula. It describes 12 competencies across human-centred mindset, AI ethics, AI techniques and applications, and AI system design; it also describes three progression levels—understand, apply, and create.[3] NSOS treats this as an optional pedagogical reference only.

> A generated NSOS learning plan must identify the source profile used, present the reference URL and access date, distinguish source-informed recommendations from tenant-approved content, and require owner/admin review before any internal draft is saved.

## Research integrity rules

The initial library is intentionally small. It is not a claim of comprehensive coverage. Each new public source requires a human-readable title, organisation, URL, source category, allowed use, and review status. The agent must not infer facts absent from the source, invent citations, copy long copyrighted material, or claim that a source grants a credential or certification right.
