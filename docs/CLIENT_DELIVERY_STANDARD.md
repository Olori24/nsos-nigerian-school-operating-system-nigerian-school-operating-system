# NSOS Client Delivery Standard

An NSOS feature is complete only when its implementation is paired with role authorization, tenant isolation, validation, audit evidence, deterministic failures, idempotency where relevant, tests, security review, migration review, accessibility, mobile usability, operator documentation, cost considerations, provider boundaries, and stated limitations.

Working UI alone is not proof of a safe delivery. Likewise, a workflow definition is not proof that a remote provider, backup, restore, or production deployment has executed successfully.
